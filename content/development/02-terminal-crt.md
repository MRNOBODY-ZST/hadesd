深色背景、等宽字体、闪烁光标，三样凑齐，一个“终端”就有了。

接下来试试中文输入、选中文字、点链接，再往里面放一篇长文章。真正麻烦的部分，这时才开始。复古可以是外观，不能顺便把输入体验也送回过去。

## 这里敲的命令，去哪儿执行？

先说明白：这个终端不是远程服务器 Shell。它操作的是公开文章生成的虚拟文件系统。

一篇文章既有网页地址，也有终端路径。比如这篇文章可以在列表里点开，也可以这样读：

```text
ls
cd posts
open building-hadesd-terminal-crt.md
```

`open` 把 Markdown 渲染进终端历史；`cat` 输出原始正文；`cd` 改变虚拟目录。游客看到的 `/home/guest` 只是会话里的导航位置，不是服务器上等着被翻出来的家目录。

路径节点保留文章的 `contentId` 和 `route`。`createVfs` 建立目录，路径解析处理 `.`、`..` 和 `~`。这些逻辑放在 `packages/terminal-core`，不必和 React 的输入框、焦点、滚动挤在一个组件里。

解释器接受上下文并返回结构化结果，例如文本、错误、Markdown 或文件缓冲区，网页再决定怎么展示。它支持引号、转义和有限的 `$USER`、`$PWD` 等公开变量，但不支持管道、重定向、串联命令或命令替换。外形像命令行，不代表接上了服务器的万能遥控器。

## 文字交给 DOM，效果交给图形层

HADESD 保留真实 DOM：链接、输入框、文字选择和语义结构都在这里。`terminalTexture.ts` 测量可见文字和元素的位置，绘制到二维 Canvas，再把纹理交给 Three.js。

这不是一个“什么网页都能截图”的通用工具。它针对当前终端，不能保证复刻任意渐变、滤镜或三维 CSS 变换。

也不应该每帧把全文重新读一遍。内容、尺寸、输入、滚动、选择和字体加载等变化会让纹理失效，再合并到动画帧里刷新。可见字符、元素数量和纹理尺寸都有预算。

这个预算有个容易忽略的细节：屏幕外的文字不能抢先把额度吃光。否则长篇 `cat` 输出滚到后半段时，DOM 里明明有字，Canvas 却已经“今日额度用完”。这种限制应该控制工作量，而不是把文章后半截扣下来。

跨域图片还可能污染 Canvas。当前实现用原生图片叠层处理不适合进入纹理的图片，按终端区域裁剪，不假定每台图片服务器都会配合开放跨域读取。

## 扫描线可以留，字不能散架

图形层使用 Three.js 的 `WebGPURenderer`，支持 WebGPU 与 WebGL2 后端，由 React Three Fiber 组织场景。扫描线、辉光、暗角等效果都发生在显示阶段。

问题是：屏幕上画出的链接，必须和真实 DOM 的点击区域对得上。画面扭曲得很有年代感，鼠标却点不到链接，这就不是怀旧，而是在给读者出操作题。

开场可以强调空间变化，稳定阅读阶段则要收敛色散和几何扰动。ASCII 横幅还需要单独照顾等宽字体和行高；方块字符之间一旦被普通正文的行距撑开，字就像拆散后还没装回去的积木。

关闭 CRT、进入专注阅读、系统要求减少动态效果或 GPU 初始化失败时，需要有原生显示路径。打印和无 JavaScript 阅读也不能等动画播放完才交出正文。

## 两种 Enter，不能混为一谈

英文输入时，Enter 通常表示提交命令；中文输入法选词时，它可能只是“这个字，就它了”。组合输入期间，Enter、方向键和光标移动都要与提交命令、切换历史分开处理。

长文滚动也有类似区别：用户是在跟随最新输出，还是正在回看旧内容？界面记录每次输出的位置，并区分这两种状态。否则新消息一来，页面把人拖到底部，刚找到的段落又没了。

账号命令更不是简单的字符串处理。`login`、`register`、`passwd` 需要隐藏输入、取消和异步请求。敏感参数要从历史中脱敏，退出或身份变化时清理私有输出。

Vim 风格缓冲区的 `:w` 也要看身份：管理员能保存服务器草稿，普通读者保存的是浏览器本地副本。长得像同一条命令，权限仍由服务端决定。

## 片头结束，不只看进度条

开场分成这些阶段：

```text
boot → pullback → hero → journey → resume → penetrate → reveal → terminal
```

部分阶段由时间驱动，介绍与旅程主要由滚动、触屏或键盘推进。用户停下，旅程也应该停下。

“滚动值到 1”和“终端已经可以输入”是两件事。真正解锁交互的是 `terminal` 状态。图形帧还需要读取一致的阶段与进度，不能拿上一阶段的名字，配下一阶段刚归零的进度，否则容易出现回闪。

验证时也要分开看：路径测试证明不了像素是否清楚，截图证明不了退出后私有输出是否清空。中文输入、长文滚动、缩放、资源释放和 GPU 回退都需要各自检查。
