# 可自行部署的终端博客与 README 演示

**目标**：新使用者能够用独立配置部署自己的博客；README 中用真实界面的 GIF 展示终端操作。

**范围**：保留 HADESD 项目及终端/CRT 风格，支持一套部署对应一个站点。使用现有内容、账号、发布和存储架构，不增加多租户平台。

**约束**：保留工作区已有前景效果修改；不读取或覆盖现有私有配置，不修改正式数据库或部署线上；不新增运行时依赖；既有站点设置及历史快照兼容。

## 设计

- 身份：后台现有名称、标语、简介、首页文案和链接继续是权威配置；补充可选开场标题。新安装使用中性默认值；旧快照缺少字段时保留原开场标题。数据库中未保存设置但已有成功快照的站点由新迁移回填。
- 地址：SITE_ORIGIN 是部署级站点地址，预渲染 canonical、Open Graph、RSS、sitemap、robots 与 Worker 使用同一验证规则，默认本地地址，不隐式链接到原作者域名。
- 部署：新增独立 Docker 入口与可配置初始化，使用独立环境文件/数据位置/Compose 项目，宿主只需要 Docker Compose；保留源码开发方式和现有生产专用配置。
- 演示：使用无敏感信息的公开 fixture，在专用本地服务录制真实终端输入、目录与 Markdown 阅读，生成可循环 GIF 和复现脚本，README 使用相对链接嵌入。

## 执行与验证

- [x] 部署子任务：初始化参数、旧配置保护、独立Compose与启动入口；先验证失败用例，再实现，校验独立临时配置。
- [x] 身份子任务：共享契约、后端默认值、兼容迁移和验证；覆盖旧JSON/新字段/已有设置保护。
- [x] 前端子任务：开场/终端/首页使用设置，后台编辑开场标题；覆盖自定义身份渲染并检查旧快照行为。
- [x] 地址子任务：消除公开元数据中的个人域名，覆盖安全校验及自定义域名下静态产物和导航后的meta。
- [x] GIF子任务：录制实际UI、查看代表帧、校验尺寸/帧数/时长/体积，保留复现入口。
- [x] 文档：README面向安装者，加入GIF、Docker快速开始、自定义站点、升级与备份边界。
- [x] 集成核验：运行受影响单测、类型检查、前端构建、隔离浏览器身份与SEO验证，审阅差异与文档命令。

## 验证结果

- 工作区测试 313 项、后端 Testcontainers 测试 48 项、根脚本测试 52 项通过；类型检查、公开示例快照下的前后台构建、Shell 语法与差异检查通过。
- 独立 Docker 安装完成初始化、构建、管理员创建与登录、重启、重复初始化保护、空站发布；测试资源已清理。
- 真实 Nginx 请求验证 HTTPS 同源与转发头清洗，以及显式可信代理下的访客 IP 区分；默认拒绝伪造地址。
- 桌面与手机验证自定义身份、开场标题、旧快照回退、管理端字段和客户端导航元数据，无横向溢出。
- GIF 为 1000×760、43 帧、17.55 秒、294989 字节；录制无外部请求。文档 54 个本地链接（含图片与锚点）全部有效。
- 独立复核发现的私有路径、派生目录符号链接、代理限流问题均已修复并复核闭合。构建保留已有的大分块提示，未执行整套有业务写入的 Playwright E2E 或线上部署。

## 文件边界

部署工作限于 setup/deploy 脚本、Compose、根脚本条目；后端身份工作限于 backend 与 contracts 类型；演示工作限于录制脚本、fixture 和 docs/assets；root负责 web/admin、origin共享模块、README和集成核验。共同接口为 SiteSettings.heroTitle（可选）及 SITE_ORIGIN；项目名保留 HADESD，不增加额外站点身份环境变量。
