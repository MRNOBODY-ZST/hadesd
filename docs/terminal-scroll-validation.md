# 原生滚动终端（2026-09-12）

本次从 GitHub `a4c7851` 拉取后修改前端虚拟终端，保留 Spring Boot 4.1.1、Java 25、WebFlux、R2DBC、Reactive Redis 与私有 MinIO 后端。

## 行为

- 目录状态独立于网页路由；游客从 `/home/guest` 出发，`cd ..` 依次到 `/home` 与 `/`，`cd` 回家、`cd -` 返回上次位置，登录后切换用户家目录。
- 命令及其当时的提示符保留在原生滚动历史中；长文从开头显示，输入保持焦点，↑↓ 召回历史，PgUp/PgDn 滚动。Markdown 阅读、源码查看和 Vim 编辑分别使用 `md/open/less`、`cat`、`vim`。
- 注册、登录、资料、密码、个人文件与评论使用文字提示。密码不进入输出、补全或命令历史；切换账号清理私人输出。上传仅调用浏览器原生文件选择器，结果仍写入终端。
- 增加常用 Linux 文件查看和文本处理命令，详细语法见 [terminal-core](../packages/terminal-core/README.md)。这是浏览器内的虚拟文件系统，公开博客内容保持只读。
- CRT 绘制跟随原生滚动，选择高亮、HTTPS 图片和滚动条按可见区域裁剪；长日志尾部不会因绘制预算变空白。原 DOS／Mac／ASCII 片头保留。
