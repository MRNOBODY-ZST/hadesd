# 博客与终端交互

公开站点的读者账户、评论和个人文件与已有作者写作台使用同一个 Reactive 后端。Spring Boot 4.1.1、Java 25、WebFlux、R2DBC 和 Reactive Redis Session 沿用现有版本；数据库迁移扩展账号、评论和附件引用关系，旧文章及其发布历史保留。

## 使用

输入 `register` 或 `login`，终端依次询问用户名、昵称和密码。每次回车提交一项；密码使用隐藏输入，不进入命令历史，Ctrl+C 取消。上方登录/注册按钮也进入同一文字流程。`profile` 查看身份，`profile edit` 修改昵称，`passwd` 修改密码，`logout` 退出。管理员使用同一账号登录 `/admin/` 写作台，或在终端 Vim 保存已有文章的服务器草稿。
文章图片、附件与用户文件共用私有 MinIO 桶，通过后端 API 访问。正文与修订仍存储在 MySQL；MinIO 配置、原附件迁移及备份见 [minio.md](minio.md)。

文章底部提供评论、回复、编辑和删除。执行 `comment` 后逐行输入 Markdown，单独一行 `.` 结束，再输入 `y` 确认公开发布。`.attach <文件 ID>` 可以附加最多四个已上传附件，`.clear` 清空输入，`.preview` 查看草稿原文。回复、编辑和删除按钮也启动文字提示。图片直接显示并提供原图与下载链接；文件在「我的文件」中默认私有，发布为评论附件后才公开，移除公开引用后撤销访问。服务器拒绝借用他人文件、编辑他人评论、访问未发布内容和绕过 CSRF 的写入。

写作台支持选择、拖放或粘贴图片与文件。上传期间可以继续编辑，完成后在原位置插入实际地址；失败不会留下可发布的临时占位。Markdown 预览使用私有媒体地址，正式文章使用当前发布引用允许的公开地址。

## Markdown

支持 GFM 表格、任务列表、删除线、自动链接、脚注、行内与块级数学公式、语法高亮、代码复制、提示块和折叠内容。目录和标题通过同一 AST 生成，避免带格式、重复标题或代码围栏导致目录不匹配。Mermaid 保留原代码，点击「渲染 Mermaid 图表」后才加载图表引擎；渲染错误显示说明，原始正文仍可阅读。原始 HTML 不执行，数学关闭信任模式，图表 SVG 净化后作为独立图像显示。

HTTPS 外链图片允许显示；无法加载时显示替代文字和原图链接。GPU 终端对不能读取像素的跨域图片使用独立原生图层，按原生滚动位置和可见区域裁剪；阅读模式使用原生 DOM。图表引擎按需加载，不在普通首页启动时执行。

## 终端

终端保留可上下滚动的命令输出，长文章从开头显示，短输出跟随底部。鼠标滚轮、触摸或 PgUp / PgDn 都可以直接阅读历史，不用先点击 Section。点击「↓ 最新」返回末尾。屏幕外层仍固定以保留 CRT，内部使用原生滚动。

| 操作 | 行为 |
| --- | --- |
| Tab / Shift+Tab | 补全命令、路径与参数，循环候选 |
| Ctrl+Space；Esc 后 Tab | 显示候选；退出补全并继续原生焦点遍历 |
| ↑ / ↓ | 在命令框召回历史，并保留未提交的输入 |
| PgUp / PgDn | 保留输入与焦点，滚动历史内容 |
| Ctrl+C / Ctrl+L | 中断命令或文字交互；清屏 |
| Ctrl+U / Ctrl+K / Ctrl+W | 删除光标前文字、光标后文字、前一个单词 |
| `pwd` / `cd ..` / `cd -` / `cd` | 查看路径、上级目录、上次目录、回家目录 |
| `ls -la` / `tree` / `find` | 浏览虚拟文件目录 |
| `open` / `less` / `md` / `preview <file>` | 在历史中渲染完整 Markdown、图片、代码、表格与公式 |
| `cat` / `head` / `tail` / `grep` / `wc` | 读取原文、查看首尾、过滤行与统计 |
| `whoami` / `env` / `uname` / `date` / `uptime` | 查看会话身份、公开环境与时间 |
| `help` / `man <command>` | 查看完整命令说明和示例 |
| `vim <file>` | 独立 Vim 编辑；`:w` 保存，`:wq` 保存退出，`:q!` 放弃修改 |
| `files` / `upload` / `download <ID>` / `files rm <ID>` | 查看、上传、下载和删除个人文件；上传调用浏览器本地文件选择器 |
| `comments` / `mycomments` / `comment` | 查看文章评论、我的评论、逐行发表评论 |
| `comment reply <ID>` / `comment edit <ID>` / `comment rm <ID>` | 回复、编辑或确认删除评论 |

游客从 `/home/guest` 开始，登录后家目录为 `/home/<用户名>`。`~` 指向家目录；`cd ..` 可依次走到 `/home` 和 `/`。博客目录在根目录和家目录内均可访问。目录状态独立于网页路由，历史提示符保留命令执行时的用户名和路径。`search`、`tag`、`about` 等命令同样在历史中追加结果。

该终端在浏览器内模拟 Linux 常用命令，公开文件为只读；不会执行服务器 Shell。命令支持引号、转义、公开环境变量及光标中间补全。管道、重定向和任意系统程序不在当前命令范围。历史保留最近 100 条命令，输出保留最近 250 条记录；刷新结束本次会话历史。密码相关参数被隐藏，交互答案不会进入命令历史；退出或切换账号时移除该账号的私人输出。

Vim 最初显示已发布源码。管理员按 `i` 时才读取最新服务器草稿，`:w` 保留标题、摘要、标签、封面等元数据并创建新修订；版本冲突不会覆盖另一处修改。保存不会自动发布。普通读者按 `i` 编辑浏览器本地副本，`:w` 存入 `hadesd.vim.local.v1:<path>`，下次按 `i` 可以继续；界面始终标注 `LOCAL COPY`。浏览器拒绝存储时报告失败并保留当前文字。
