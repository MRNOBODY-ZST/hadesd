# 博客与终端交互

公开站点的读者账户、评论和个人文件与已有作者写作台使用同一个 Reactive 后端。Spring Boot 4.1.1、Java 25、WebFlux、R2DBC 和 Reactive Redis Session 沿用现有版本；数据库迁移扩展账号、评论和附件引用关系，旧文章及其发布历史保留。

## 使用

屏幕上方的「登录」「注册」按钮打开账户表单。注册成功后登录，可以修改显示名称、修改密码、管理自己的文件和查看自己的评论。管理员账户进入 `/admin/` 继续写作与发布，普通读者在后台入口会得到明确的返回博客提示。

文章底部提供评论、回复、编辑和删除。正文支持 Markdown 预览，每条可上传或选择最多四个附件。图片直接显示并提供原图与下载链接；文件在「我的文件」中默认私有，发布为评论附件后才公开，移除公开引用后撤销访问。服务器拒绝借用他人文件、编辑他人评论、访问未发布内容和绕过 CSRF 的写入。

写作台支持选择、拖放或粘贴图片与文件。上传期间可以继续编辑，完成后在原位置插入实际地址；失败不会留下可发布的临时占位。Markdown 预览使用私有媒体地址，正式文章使用当前发布引用允许的公开地址。

## Markdown

支持 GFM 表格、任务列表、删除线、自动链接、脚注、行内与块级数学公式、语法高亮、代码复制、提示块和折叠内容。目录和标题通过同一 AST 生成，避免带格式、重复标题或代码围栏导致目录不匹配。Mermaid 保留原代码，点击「渲染 Mermaid 图表」后才加载图表引擎；渲染错误显示说明，原始正文仍可阅读。原始 HTML 不执行，数学关闭信任模式，图表 SVG 净化后作为独立图像显示。

HTTPS 外链图片允许显示；无法加载时显示替代文字和原图链接。GPU 终端对不能读取像素的跨域图片使用独立原生图层，按正文位置与当前分页裁剪；阅读模式使用原生 DOM。图表引擎按需加载，不在普通首页启动时执行。

## 终端

| 操作 | 行为 |
| --- | --- |
| Tab / Shift+Tab | 补全命令、路径或命令参数，多候选时正向 / 反向循环 |
| Ctrl+Space | 显示补全候选 |
| Esc 后 Tab | 离开命令框，继续键盘遍历 |
| PgUp / PgDn | 命令框聚焦时也可连续翻屏，保留未提交文字 |
| j / k、方向键、空格 | 非表单输入时翻屏 |
| `login` / `register` | 打开账号表单，密码只在密码框输入 |
| `profile` / `logout` | 打开账户或退出登录 |
| `comments` | 返回当前文章并定位评论区 |

命令参数按命令类型补全，支持带空格的文件名、引号、转义和插入点中间编辑。账户命令意外携带的参数不会进入显示历史，避免误输入密码时回显。中文输入法组合期间不触发命令或补全；评论和资料表单保留自己的键盘行为。
