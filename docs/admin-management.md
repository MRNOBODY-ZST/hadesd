# Admin 外观与资料管理

## 四套外观

写作台右上角“外观”可选择纸张手记、石墨夜间、冰川工作台、琥珀终端。预设覆盖导航、表单、正文预览、评论和操作状态，分别调整配色、字体和间距。偏好保存在这台浏览器中；同源其他标签页同步更新。启动脚本在界面载入前应用选择，遵守原来的仅同源脚本 CSP。没有新增 UI 框架或修改公开终端的外观偏好。

## 文稿

列表搜索覆盖整个资料库的标题与链接标识，不区分大小写，并可按类型筛选。文稿与回收站分别分页。

“移入回收站”保留正文和历史修订；“恢复文稿”恢复为私有草稿，不自动发布。在线文章必须先撤稿，且发布任务结束后才能移入回收站。回收站中的文稿只读，保存、发布及会重新带回该文稿的回滚都要求先恢复。删除与恢复携带版本号，另一个窗口的更新不会被覆盖。

回收站提供明确确认的“永久删除”，仅清理从未发布且没有保留版本、评论引用的文稿及其修订。媒体文件本身不随文稿永久删除；文稿引用释放后可从媒体库的“未引用”筛选继续清理。已有发布历史的文稿受到保护；迁移前已经过期的快照无法证明其包含哪些修订，相关旧记录保守保留。

## 媒体

媒体库支持文件名或 ID 搜索、图片/文本/PDF/ZIP 类型筛选、引用状态筛选，以及每页 20 项的分页。引用详情会列出最新草稿、旧修订及站点版本，可跳转到文稿查看。

可以选择本页文件批量删除。服务器逐项返回结果，受保护文件或单项失败不会让已成功删除的项目显示为全部失败。没有引用的文件可删除；最新草稿（含回收站）和发布历史中的文件受保护。若仅被从未发布的旧修订引用，可以额外确认清理这些历史引用；确认说明中明确提醒该历史文件不可恢复。

选择或拖入多个文件可批量上传，最多 50 个、同时 3 个请求。每个文件都有实际结果与进度；一项失败不丢弃其他成功项。编辑器侧栏默认每页 6 项小缩略图，搜索覆盖全库，支持翻页、插入正文与设为封面。独立资料管理入口可处理批量操作。

对象删除采用数据库持久任务：引用检查和数据库更新先在事务内完成，再删除 MinIO 对象；临时存储故障保留任务后台重试。未成功完成的删除会提示刷新核对，不把仅收到请求视为对象删除完成。

## 服务端接口

- `GET /api/v1/admin/contents?page=&size=&q=&type=&trash=`
- `DELETE /api/v1/admin/contents/{id}?version=`：回收站。
- `POST /api/v1/admin/contents/{id}/restore`，正文 `{ "version": 1 }`。
- `DELETE /api/v1/admin/contents/{id}/purge?version=`：明确确认后的永久删除。
- `GET /api/v1/admin/media?page=&size=&q=&type=&referenced=`。
- `GET /api/v1/admin/media/{id}/references?page=&size=`。
- `POST /api/v1/admin/media/batch-delete`，正文 `{ "ids": ["…"], "discardUnusedHistory": false }`，最多 50 个不同 ID。

接口继续使用 ADMIN 权限、会话和 CSRF。数据库变更由 Flyway V5 执行；后端仍是 Spring Boot 4.1.1、Java 25、WebFlux/R2DBC/Reactive Redis。媒体读取与 Cloudflare 缓存的区别见 [媒体访问说明](media-delivery.md)。
